# Deploying ExpenseIQ for free (permanent public URLs)

ExpenseIQ is a **live Python server app** (FastAPI backend + Streamlit dashboard +
XGBoost model + SQLite). It cannot be hosted on **Vercel, Netlify or GitHub
Pages** — those platforms serve static sites and short-lived serverless
functions, not a persistent Python process with websockets and a loaded ML
model. The free hosts below run real Python servers.

Demo login for every deployment: **`demo@expenseiq.app` / `demo1234`**
(the database is seeded automatically with 11,494 transactions on first start).

---

## Option A (recommended) — Render, one click, two free URLs

Everything is pre-configured in [`render.yaml`](render.yaml).

1. Push this branch to GitHub (already done if you're reading this from the repo).
2. Go to <https://dashboard.render.com> → **New** → **Blueprint**.
3. Connect your GitHub account → select `badhurudeen7863/capstone-phase-2` →
   branch `arena/cdfb089c-capstone-phase-2` → **Apply**.
4. Render creates two **free** web services and prints their URLs:
   - API: `https://expenseiq-api.onrender.com` (interactive docs at `/docs`)
   - Dashboard: `https://expenseiq-dashboard.onrender.com`
5. Open the dashboard URL, log in with the demo credentials above.

Notes:
- No credit card required. Free services sleep after 15 min of inactivity;
  the first request after that takes ~30–60 s (cold start).
- The SQLite demo DB lives on an ephemeral disk, so `scripts/seed_db.py` runs
  automatically on every start (it is idempotent — existing rows are skipped).
- `SECRET_KEY` is auto-generated by the blueprint; `API_BASE_URL` for the
  dashboard is wired to the API service automatically.

## Option B — Streamlit Community Cloud (dashboard) + Render (API)

If you prefer Streamlit's own host for the dashboard:

1. Deploy **only the API** on Render (same blueprint, or a single web service
   with start command
   `python scripts/seed_db.py && uvicorn backend.main:app --host 0.0.0.0 --port $PORT`).
2. Go to <https://share.streamlit.io> → **New app** →
   repo `badhurudeen7863/capstone-phase-2`, branch
   `arena/cdfb089c-capstone-phase-2`, main file `frontend/app.py`.
3. Under **Advanced settings → Secrets**, add:
   ```toml
   API_BASE_URL = "https://expenseiq-api.onrender.com"
   ```
4. Deploy. You get a free `https://<your-app>.streamlit.app` URL.

## Option C — Hugging Face Spaces (single URL)

A free HF Space (`https://<space>.hf.space`) can run both processes from one
container (start `uvicorn` in the background, then `streamlit run` in the
foreground). Say the word and a launcher script + space config can be added.

## Adding a free domain / nicer URL

The `*.onrender.com` and `*.streamlit.app` URLs are already free and permanent
for the life of the services. If you want a custom-looking free domain:

1. **DuckDNS** (<https://duckdns.org>, free, 2-minute signup):
   pick e.g. `expenseiq.duckdns.org`, then set its **A record** to the IP of
   `expenseiq-dashboard.onrender.com` (`dig expenseiq-dashboard.onrender.com`).
   Caveat: Render free-tier IPs can change, so you may need to update the record
   after long idle periods.
2. **FreeDNS / afraid.org** (free): choose one of their shared subdomains and
   set a **CNAME** to `expenseiq-dashboard.onrender.com` — no IP tracking needed.
3. If you later register a real domain (or get a free one from `eu.org` /
   `pp.ua` / `us.kg`), point a CNAME at the same host — or serve the dashboard
   from Cloudflare's free plan in front of it.

## Local run (zero setup)

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/seed_db.py
.venv/bin/uvicorn backend.main:app --host 0.0.0.0 --port 8000        # API
API_BASE_URL=http://127.0.0.1:8000 .venv/bin/streamlit run frontend/app.py  # dashboard
```
